Demo notes

What is real, what is simulated

This is a UI prototype. It runs entirely in the browser and no files leave this machine. The workflow, review model and report structure are real; the AI pass and the export are simulated for the demo.

Media

  • Photos — real 360° captures, used as labelled placeholders. Classroom: “Classroom — Golden Jubilee Bhavan…” by Biswarup Ganguly, CC BY 3.0, Wikimedia Commons. Hall: “Large Corridor” by Sergej Majboroda, Poly Haven, CC0.
  • Floor plan — “Reliance Building typical floor plan” (1906), public domain, Wikimedia Commons. Cropped to remove the caption and used as a redacted reference plan.

Keyboard

  • ←→ move between findings
  • 1–4 set the active layer
  • Enter keep finding
  • X not a defect
  • R reset the demo

Replace assets/photos/ and assets/floor-plan.png with your own project files. The README explains the structure and the attribution.
